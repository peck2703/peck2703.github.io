# Data Structures & Algorithms

## Project Overview
A complex data structures project focused on algorithmic optimization, computational complexity analysis, and intensive performance benchmarking.

[View Source Code on GitHub](https://github.com){: .btn .btn--primary target="_blank"}

## Technical Deep Dive

### Architectural Overhaul
* **Legacy System:** Standard binary search tree structure presenting sub-optimal performance under scale.
* **Optimized Architecture:** Refactored into a hybrid dual B+ Tree and Trie algorithm structure.

### Performance & Benchmarking
* **Stress Testing:** Benchmarked system performance continuously using datasets scaling from 10 directly up to 300 records.
* **Optimization Results:** Quantifiably proved significant search-time reductions, driving Big O operational complexity down to ideal metrics.
