## Project Overview
A fully migrated MEAN stack application that demonstrates mastery of Single Page Application (SPA) architecture, custom routing, and API integration.

[View Source Code on GitHub](https://github.com){: .btn .btn--primary target="_blank"}

## Technical Deep Dive

### Architecture & Frameworks
* **Frontend:** Angular SPA architecture utilizing custom client-side routing, modular components, and real-time data binding.
* **Backend:** Node.js and Express.js REST API providing clean separation of concerns and decoupled service layers.
* **Database:** MongoDB managing flexible, document-oriented persistence layouts.

### Key Implementations
* **Decoupled Architecture:** Migrated static structures into a production-ready, dynamic ecosystem using full-stack patterns.
* **Custom Routing:** Secured client-side routing to manage view states smoothly without page reloads.
* **API Integration:** Formed end-to-end communication channels between the Angular client layer and the backend controllers.
