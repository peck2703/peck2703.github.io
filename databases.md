# Database Systems & Security

## Project Overview
An ambitious Android mobile inventory application featuring secure CRUD API interactions, cloud database synchronization, and direct hardware integration.

[View Source Code on GitHub](https://github.com){: .btn .btn--primary target="_blank"}

## Technical Deep Dive

### Data Modeling & Storage
* **Local Layer:** Local SQLite caching mechanism to maintain offline persistence states.
* **Cloud Layer:** Hosted PostgreSQL (Supabase) backend infrastructure supporting live operational datasets.
* **Normal Form:** Rigorously modeled according to Third Normal Form (3NF) structures to eliminate storage redundancies.

### Security & Hardware Integration
* **Parameterized Queries:** Mitigated critical SQL injection threats completely through structured API calls and parameter binding.
* **Hardware Interfacing:** Leveraged native mobile device cameras to drive real-time barcode scanning systems directly into the application loop.
